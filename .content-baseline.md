# Enterprise Field Academy content baseline

The pre-redesign site is preserved intact in `legacy-course.html`. It remains the
complete offline course and contains the embedded 75-module hands-on lab.

Content areas confirmed before the shell redesign:

- Linux basics, storage, networking, services, packages, processes, and logs
- Break/Fix field scenarios
- Red Hat Satellite, content lifecycle, disconnected operations, and containers
- IdM, certificate mapping, CAC, and smart-card authentication
- ACAS / Tenable Security Center and Nessus
- STIG, SCAP, OpenSCAP, and SELinux
- Updates, patching, lifecycle, and rollback planning
- Bash and cron
- VMware vCenter / ESXi, storage, networking, upgrades, and snapshots
- Veeam and recovery guidance in the embedded lab
- Wazuh and vendor source references

Safety baseline retained by the redesign:

- `rm -rf` is not a normal troubleshooting shortcut.
- `kill -9` is not a first response.
- Disabling SELinux is not a normal fix.
- STIG remediation requires review, testing, and recovery planning.
- A snapshot is not a backup.
- Vendor-specific backup and upgrade workflows remain authoritative.
- Examples use sanitized `.example.test` names and documentation IP ranges.

This file is an inventory and preservation marker, not a replacement for the
course content in `legacy-course.html`.
